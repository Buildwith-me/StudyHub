OPERATING SYSTEM NOTES

1. Introduction
An Operating System (OS) is system software
that manages computer hardware and software.

2. Examples
- Windows
- Linux
- macOS
- Android

3. Functions of Operating System
- Process Management
- Memory Management
- File Management
- Device Management
- Security Management

4. Types of Operating Systems
- Batch Operating System
- Time Sharing Operating System
- Distributed Operating System
- Real Time Operating System

5. CPU Scheduling Algorithms
- FCFS (First Come First Serve)
- SJF (Shortest Job First)
- Round Robin
- Priority Scheduling

6. Memory Management
Memory management controls the allocation
and deallocation of computer memory.

7. Deadlock
Deadlock occurs when processes wait
indefinitely for resources.

8. Applications
- Running applications
- Managing files
- Controlling devices
- Managing system resources
