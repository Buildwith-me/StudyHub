WEB DEVELOPMENT NOTES

1. Introduction
Web development is the process of creating
websites and web applications.

2. HTML
HTML stands for HyperText Markup Language.
It creates the structure of a webpage.

Basic Tags:
- <html>
- <head>
- <title>
- <body>
- <h1>
- <p>
- <a>

3. CSS
CSS stands for Cascading Style Sheets.
It is used to design and style webpages.

Important Properties:
- color
- background-color
- margin
- padding
- border
- font-size

4. JavaScript
JavaScript makes webpages interactive.

Concepts:
- Variables
- Functions
- Arrays
- Objects
- Conditions
- Loops
- Events

5. Types of Web Development
- Frontend Development
- Backend Development
- Full Stack Development

6. Applications
- E-commerce websites
- Educational websites
- Social media websites
- Banking websites
