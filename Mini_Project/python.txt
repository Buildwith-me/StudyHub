Python is a high-level programming language.
It is easy to learn and understand.

2. Features of Python
- Easy to read
- Simple syntax
- Open source
- Platform independent
- Object oriented

3. Data Types
- Integer
- Float
- String
- Boolean
- List
- Tuple
- Dictionary

4. Variables
Variables are used to store data.

Example:

5. Conditional Statements
